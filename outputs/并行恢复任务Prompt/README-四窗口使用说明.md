# 四窗口并行恢复使用说明

四个新窗口分别读取41、42、43、44号Prompt。每份说明包含当前工程状态、精确负责范围、证据、专用IDA快照、候选/测试/报告与handoff要求。各窗口在自己的work目录完成可执行候选；本主窗口统一合入并执行Unity实际运行。

四个专用IDA数据库已经从关闭状态的工作库复制，可直接使用；不要同时打开主窗口的framework.i64。总计额外占用约3.8GB。请勿手工让新窗口开同一Unity工程。

新窗口完成后，将它的threadId或handoff路径发给主窗口即可。即使没有跨窗口消息权限，handoff文件仍可让主窗口读到完整结果。
