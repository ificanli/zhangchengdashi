# 占城大师恢复到 Unity：过程报告与学习导航

目标：将 MuMu 中的占城大师恢复到独立 Unity 工程，并验证原资源场景和核心玩法实际运行。本目录持续更新，最后按相同顺序阅读可以看到完整的推理、失败与修复过程。

**恢复已按用户要求暂停，尚未达到完整运行目标。** 四个新窗口的配置、FSM、地图/开格及Shader结果已全部合入，另合入44战斗197原方法。五批共339原正文，38必要主键getter随后接入；源码/meta保护与必要独立检查通过。真实GUI Shader/绑定读回通过，Main6观察45秒/22快照/Error0，但帧后半段固定1803、游戏时间约9.987，仍只抵达Version，实际startupProvider最后取消。独立私有资源Probe2通过，不等于原启动或玩法通过。工程、全部报告和原始分析资料准备上传用户指定GitHub仓库；地图、开格/占领、兵堆战斗仍未验收。

## 贯穿整个过程的四个区别

1. 类型声明与字段布局可以恢复，不意味着原方法实现已恢复。
2. 资源能打开，不意味着自定义脚本字段和跨资源引用都正确。
3. 工程能编译，不意味着异步初始化、数据和玩法可以运行。
4. 方法在独立测试中正确，不意味着已经在Unity场景内调用并产生正确表现。
