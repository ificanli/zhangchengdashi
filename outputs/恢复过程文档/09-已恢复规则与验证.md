## HexDistance：不能忽略整数边界

普通地图坐标下，公式是三项轴向差绝对值之和除二。但原ARM64使用32位SUB/CNEG/ADD，全部允许回绕。C#的`Math.Abs(int.MinValue)`会抛异常，与原指令不同。

恢复代码因此使用`unchecked`内的条件取负，并保留有符号整数除二向零截断。证据RVA为`0x3D2A600`；HexCoord按值传入，两个坐标分别占x0、x1。

## InternalCalculateDamage：不能把浮点路径换成整数除法

证据RVA为`0x3E0F6F0`，真实指令为SCVTF→FMUL 0.5→FCVTZS→32位ADD。方法本身不使用isEnemy。

```csharp
if (fetterCount < requiredCount)
    return originalAttack;
float bonus = (float)originalAttack * 0.5f;
return unchecked(originalAttack + (int)bonus);
```

攻击16,777,219在float32中先舍入到16,777,220，正确结果为25,165,829；直接整数除二会少1。这个差异是恢复正确性需要保留的行为，不应“优化”掉。
