## 原始证据与恢复边界

原 ELF 的本地有界读回包含 47 个方法、15,104 个 native 字节。主线程额外运行 17 个启动目标和 4 个 typed-resource 目标的 IDA 反编译，状态、伪代码与汇编均收入证据目录。

- UpdateManager：原单例的实际 GameObject 查找/创建、组件取得与 DontDestroyOnLoad；原构造分配和初始容量。
- AppSetting：只恢复 MineGameName 原 getter/setter，其他属性未扩大恢复范围。
- VersionMondule：Priority=130、原 Initialize 分支、协程启动、缓存字典与构造初始化；完成时先绑定真实 IBundleServices，再写本模块原 bool、记录日志、调用原回调。
- AssetbundleModule：恢复启动所需字典、协程宿主和完成顺序；Editor 使用明确命名的资源边界，不生成虚构 AssetBundleManifest。
- ResourcesModule：原构造分配、ResourcesMono 对象、原 firstpack 判断及回调顺序；Editor loader 队列实际完成 typed load 后才交付回调，保持 UIModule 的 LoadPrefab→Update(0,0) 合约。
- ResourcesInfo：仅 typed LoadAsset<T> 与 Instantiate 所需 I/O 边界接入实际资源 provider。原 Instantiate 的 bool 经 native 证实为 active，实际实例化后设置激活、原名并写入对象收据。
- PatchManifest：原 header/record parser、字典、必要 getter 与 TryGetValue。保留空字段、Convert 转换、Dictionary.Add 重复键失败及原记录版本语义。
- BundleAssetInfo 由平行代理独占恢复，本阶段只消费其已稳定的两个原构造与字段访问器；源 SHA256=`67f6842b7585e4cbc78b88311b72cfd9018f205b29f84cbaeb10e5c1e4dce585`。

完整 native Android SDK、下载、delivery、AssetBundleManager/AssetBundleManifest 状态机未完成恢复。本阶段的 Editor I/O 是显式平台适配，原 nested dummy 状态机仍未作为已恢复 native 行为宣称。所选未实现平台入口明确抛出诊断，未用空成功代替。更广的原资源 API 与基础 ResourcesInfo.isReady 不在本阶段启动窄范围中。

## firstpack 缺失分支的直接依据

真实 APK 的 34 条清单没有 `firstpack.unity3d`。原 GetAssetBundleInfo 的缺失分支在 `0x72EF468–0x72EF488` 将请求 key 与 String.Empty 传入短构造 `0x72EB4AC`；该构造保存原请求 Name 与空 LocalPath。ResourcesModule 的原分支实际读取 `+0x20` 的 LocalPath。因此返回 Name=`firstpack.unity3d`、LocalPath=空串是原始缺失记录语义，不是以空 Name 跳过判断。

## 实际 Editor 资源路径与必需验收

Provider 独立 Editor asmdef 引用 GFRunning、官方 Addressables Editor/Runtime 和 ResourceManager，GFRunning 不增加 UnityEditor/Addressables 引用。其执行顺序为：

1. 实际加载导入 registry，检查选定 APK 的 SHA256 和原加密 ABFiles 身份；实际 Unity TextAsset 读取解码清单，并由原 parser 得到 34 条记录。
2. 从实际 APK ZIP 读取全部 34 个 payload，逐项验证原声明长度与 MD5，保留真实 payload 数据。
3. 通过 AssetDatabase 实际 typed load 全部 50 个原 TextAsset，逐项核对 name/type/GUID/长度/字节哈希；其中 41 个为原 ConfigMgr 直接消费者。两份原 5 字节空表保持原始字节。
4. 实际 typed load 原映射 UIRoot GameObject，检查已审查 prefab 哈希、RectTransform 和层级无 missing script。原身份为 `assets/gameres/bundleres/ui/uiroot.prefab`、PathID `7511370422431319846`、GUID `91dbd6641e6083543b18669ecd78d6b0`。
5. 检查实际官方 Build 报告与当前官方 settings locator 的 5,142 条 address/type/GUID 唯一映射；60 条 pending 继续保留不完整。额外实际 typed load 引导所需 GlobalMainCityMapInfo TextAsset，明确区分 locator 检查与真实加载。
6. 安装由真实清单和真实 payload 支持的 IBundleServices。先成功保存收据，再设置 Provider IsReady，之后才进入原模块完成顺序。

预期真实运行收据：`OccupyCityRecovered/RecoveryReports/local-editor-resources-receipt.json`。该文件由实际运行生成，本次冻结时尚未生成。收据记录原逻辑 key、请求/实际类型、Unity GUID/local fileId/instanceId、真实加载 API、字节哈希、firstpack 查询与真实创建实例。AssetDatabase 加载不获取 Addressables handle，因此如实记录无需 release，未伪造 handle/release。
